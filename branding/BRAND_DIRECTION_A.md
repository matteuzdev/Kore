# Kore Brand Exploration — Direction A
Status: CONCEPT, not shipped UI.
Date: 2026-10-19

## Product positioning
**KORE** — do primeiro prompt ao aplicativo real.
Promise: local-first control, transparent model choice and application ownership. Never promise a one-click deploy or features until implemented and tested.
Primary tagline: "Ideias. Apps. Realidade."

## Visual concept A
- Horizontal KORE wordmark with independent angular K emblem.
- Mascot concept: **Kai**, an angular dark robot-fox with luminous eyes, expressive yet professional; an optional communication character, not a replacement for the logo.
- Colors from visual exploration: violet `#8B5CF6`, blue `#3B82F6`, cyan `#06B6D4`, midnight `#0F172A`, off-white `#F8FAFC`.
- Typography candidate: Sora (license to be verified before bundling).
- UI intent: dark first, restrained gradients, accessible contrast, one dominant action, clear preview and diff approvals.
- Hero line: "A IA que transforma ideias em aplicações reais."
- Avoid using Dyad assets/trademarks in Kore identity; maintain legally required license credits separately.
